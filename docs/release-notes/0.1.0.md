# Vostavo 0.1.0 — draft release notes

Vostavo helps you practise speaking, record an attempt and review feedback in
English or Italian. This first macOS release is planned as an Apple Silicon DMG.
The public DMG is pending license clearance and Apple notarization.

## What is included

- A guided speaking flow with recording, transcription, assessment and a
  review that brings scores, feedback and the transcript together.
- A practice library, a scoring guide and a history view for revisiting attempts
  and tracking progress.
- Local Whisper speech recognition, plus local and cloud choices for feedback.
  Settings now explains what practice content each choice sends off the device.
- Saved connections and preferences, including five interface languages and
  system, light or dark appearance.
- Draft recovery and device-only draft protection in the signed macOS build.
  The app can resume a saved draft after an interruption.
- A smaller, clearer feedback summary and more reliable rehearsal loading.
- An About section with the app version, build commit and third-party notices.

## Release requirements

The owner must clear the bundled FFmpeg license, choose the repository's own
license, and complete notarization and clean-Mac acceptance before publishing.

These notes summarize the merged work through PR #50. They are a draft until the
public DMG has passed the release checklist.
